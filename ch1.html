Proof toolkit: examples vs proof

To break a "for all" claim, one counterexample is enough. 9 + 13 = 22, and 22 is even, so "the sum of two Book weights is in the Book" is broken.

To prove a "for all" claim, work with a general member: write a Book weight as 4m + 1, never as "say, 13". What you show for 4m + 1 holds for every one of them at once.

A legend that passed 10,000 tests may still fail at the 10,001st. In Chapter 5 one of the Vault's prophecies survives every small test and still breaks.

Theory: divisibility and the division algorithm

For integers a and d, write d | a ("d divides a") if a = dk for some integer k. An integer is even if 2 | n, and odd if n = 2k + 1 for some integer k.

Theorem 1.1 (the division algorithm)

For any integer a and any integer b > 0, there are unique integers q and r with a = qb + r and 0 ≤ r < b.

Proof. Existence. The set {a − kb : k an integer} contains nonnegative numbers (take k very negative). By the well-ordering principle it has a smallest nonnegative member r = a − qb. If r ≥ b, then r − b = a − (q + 1)b would be a smaller nonnegative member. So 0 ≤ r < b.

Uniqueness. If qb + r = q'b + r' with both remainders in [0, b), then b | r − r', and |r − r'| < b, so r = r' and then q = q'.

Theorem 1.2 (what the Book contains)

A number W is in the Book of Water if and only if W = 4m + 1 for some integer m ≥ 2. Then each hydrogen weighs h = (W − 5)/2.

Proof. If h = 2k with k ≥ 1, the weight is 2h + 5 = 4k + 5 = 4(k + 1) + 1, with m = k + 1 ≥ 2. Conversely, if W = 4m + 1 with m ≥ 2, take h = 2(m − 1), a positive even number, and check that 2h + 5 = W.

Theorem 1.3 (Vault card V1)

The product of two Book weights is a Book weight.

Proof. (4m + 1)(4n + 1) = 16mn + 4m + 4n + 1 = 4(4mn + m + n) + 1, and 4mn + m + n ≥ 2 when m, n ≥ 2. By Theorem 1.2 the product is in the Book.

Proof toolkit: induction

To prove a statement P(n) for every n ≥ 1: prove P(1) (the base case), then prove that P(n) implies P(n + 1) (the step). Like dominoes: the first falls, and each one knocks over the next.

Example. The first n Book weights (9, 13, 17, …) add up to n(2n + 7).

Proof. The k-th Book weight is 4k + 5. Base case: 9 = 1·(2 + 7). Step: if the first n weights add to n(2n + 7), adding the next one, 4(n + 1) + 5 = 4n + 9, gives 2n² + 11n + 9 = (n + 1)(2n + 9) = (n + 1)(2(n + 1) + 7).

Proof toolkit: the contrapositive

"If P then Q" is the same claim as "if not Q then not P". Example: if n² is in the Book, then n is odd. Contrapositive: if n is even, n² = 4k² is a multiple of 4, so it is not of the form 4m + 1.

Arena: El Gran Pesado's weigh-in

El Gran Pesado shouts a weight. Is it real water? If it is, name the weight of each hydrogen. If not, shout "¡Imposible!" Your crew's streak counts every right call in a row.

In class, play it as lucha rounds: one student announces the weight, every pair shows its answer at once ("¡3, 2, 1, lucha!"), and a different student explains each round. No points against each other: the whole room plays against El Gran Pesado.

Proof wrestling (class format)

One crew states a claim about the Book. The other crew gets five minutes to break it with a counterexample, or concede. A third crew judges the proof. Precise statements win: "every Book weight is odd" survives; "every odd number is a Book weight" does not.

Culture: prophecies old and new

The Maya codices. Only four Maya books survive from before the Spanish conquest. The Dresden Codex is full of counted cycles of days, used to predict the movements of Venus, eclipses and seasons of rain. Its scribes made prophecies the way you will: find a pattern, trust the arithmetic, write it down.

Odd and even in Euclid. Book IX of Euclid's Elements proves facts about odd and even numbers like the ones in this chapter, for example that an odd number times an odd number is odd.

Forecasts as prophecies. Today's El Niño forecasts are prophecies built from data: weaker Pacific winds, warmer water spreading east, then a prediction of storms in Southern California and droughts elsewhere. Like your Vault, they are tested when the season arrives.

    Answer2025 = 4·506 + 1, so yes, with h = 1010. 2026 is even, so no.

    Answer−17 = (−4)·5 + 3, so q = −4, r = 3 (the remainder must be between 0 and 4).
