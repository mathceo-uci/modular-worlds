# Modular Worlds web book

A playful first course in number theory for undergraduates (UCI Math CEO). One HTML page per chapter, shared `book.css` and `book.js`.

- `index.html` cover and contents
- `ch1.html`–`ch3.html` chapters (Explore, Prophecies, Theory, Arena, Culture, Problems, Code quest, Logbook)
- `guide-w3.html` instructor guide for Week 3
- Python cells run with Pyodide 0.26.4 (loaded on first Run)
