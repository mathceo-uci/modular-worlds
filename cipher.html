The Cipher Room

In Secret Tides, messages travel in bottles, and anyone can fish them out. Ana runs the ship's cipher workshop: number the letters, do arithmetic mod the size of the alphabet, and the message becomes nonsense to everyone but the crew. Build ciphers, crack other crews' ciphers, and make puzzle cards for them to solve.

Letters are numbers mod m

In English, A = 0, B = 1, …, Z = 25, and arithmetic is mod 26. In Spanish, with Ñ, there are 27 letters and arithmetic is mod 27. That one extra letter changes which keys work.

Shift and multiply

The affine cipher sends letter x to a·x + b mod m. With a = 1 it is Julius Caesar's shift cipher.

The key as a table

Which keys work?

Try a = 2 or a = 13 in English: some letters collide, and the message can't be undone. In Spanish, a = 2 works but a = 3 fails. A key works exactly when gcd(a, m) = 1, because then a has an inverse mod m. How many good values of a does each alphabet have? (That count is Euler's φ, Chapter 8.)

Cracking station

Why these ciphers are weak

Each letter always becomes the same letter, so the most common letter in the ciphertext is probably E (in English) or E or A (in Spanish). And there are only a few hundred keys: a computer, or a patient crew, can try them all. Real security needs far more keys, and a different idea: RSA.

Toy RSA

Pick two primes. Anyone can see n = pq and the public key e. Only you know d, which undoes e because ed ≡ 1 mod (p − 1)(q − 1).

Real keys

Factoring the toy n takes a moment. Real RSA uses primes with hundreds of digits, and nobody knows a fast way to factor their product. Encrypting stays easy with fast powers (Chapter 8), while breaking it seems impossibly hard. Chapter 9 explains why it works, and asks who it protects.
